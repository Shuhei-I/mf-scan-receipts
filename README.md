# Receipt Desk

ローカルPC上で証憑を確認し、Money Forward向け仕訳CSVを出力するアプリです。フォルダスキャン、証憑プレビュー、手入力での確認、原本を残した保管コピー、CSV出力、OpenAI APIによるOCR候補の一括取得に対応します。

## 起動

Node.js 24以降を用意し、Windowsにサインインした状態で `start-app.cmd` をダブルクリックします。Windows資格情報マネージャーを使うため、サービスや別の実行環境から起動しないでください。開くURLは `http://127.0.0.1:4175` です。

```powershell
node server.js
```

直接起動の場合は `http://127.0.0.1:4174` を開きます。終了はサーバーのコンソールで `Ctrl+C` です。

## 証憑フォルダ

証憑フォルダの場所は `.env` の `RECEIPTS_ROOT` で指定します。初回は `.env.example` を `.env` にコピーし、ご自身の証憑フォルダの絶対パスに書き換えてください。`.env` はGitの対象外です。未設定の場合はアプリ直下の `receipts` フォルダを使います。

```powershell
$env:RECEIPTS_ROOT = 'C:\path\to\receipts'
node server.js
```

画像/PDFは元の場所から表示します。経費対象として確定すると、元ファイルを残したまま `整理済み\年\YYYY-MM` へコピーします。確認前の状態変更はアプリ内DBだけに記録されます。

## データと現状の制限

- SQLiteデータベースは `data\receipts.sqlite` に作成されます。
- 対象拡張子は JPG/JPEG/PNG/WEBP/TIF/TIFF/PDF/HEIC です。
- APIキーはWindows資格情報マネージャーに保存します。OCRを実行する前に設定画面で登録してください。
- OCRはGPT-6 Lunaを使い、選択した証憑を1件ずつOpenAI APIへ送り、最大2件を同時処理します。画像/PDFの対応上限は1ファイル20 MBです。TIFF/HEICは一覧表示しますがOCR対象外です。
- 読み取った日付・支払先・金額・税額・登録番号は「未確認の候補」として保存します。候補は手動で入力欄へ反映し、原本と照合してから確定してください。
- 「証憑の税額」は証憑の記載を照合するために保持し、仕訳CSVの借方税額・貸方税額列には出力しません。税区分列とは別の項目です。
- ネットワークエラーやレート制限など一時的な失敗は1回だけ自動再試行し、失敗が続いた場合はキューから手動再実行できます。
- OCRに選んだ証憑画像/PDFはOpenAI APIへ送信されます。利用料はAPIアカウントに発生します。
- `docs\account-item-template\indiv_items_download.csv` から使用中の損益計算書科目を読み込み、OCRの勘定科目候補と入力候補に使います。個人用CSVはGit管理対象外です。ファイル選択・差し替えを行う設定画面は未実装です。
- CSVはテンプレートの27列をCP932で出力します。現時点では経費確定行を単純な1行仕訳にし、科目CSVの既定税区分を使います。複合仕訳や個別取引の税区分判断は今後の対応です。
- CSVの摘要欄には「支払先 摘要」の順で出力します。摘要が空欄、または支払先名から始まる場合は重複を避けます。
- エクスポート画面では出力月を選択できます。初期値は先月で、選択月の確定件数が0件の場合はダウンロードできません。CSVのファイル名にも年月を付けます。
- 実データでのCSV取込適合性や会計処理の正確性は、Money Forwardに取り込む前に確認してください。

## 参照CSV

- 仕訳CSVの形式見本: `docs\csv-templates\journal_sample.csv`（27列）
- 勘定科目一覧: `docs\account-item-template\indiv_items_download.csv`（個人用CSVのためGit管理対象外）
- 取引先マスタ: `docs\business-operator-template\business_operator_YYYYMMDD_HHmm.csv`（個人用CSVのためGit管理対象外。複数ある場合はファイル名の日時が最も新しいものを起動時に読み込み）

仕訳テンプレートのヘッダーをアプリ起動時に読み込み、列順に合わせてCSVを出力します。科目一覧CSVも起動時に読み込み、使用中の損益計算書科目を候補に、科目ごとの既定税区分を借方税区分に使います。CSVは各自Money Forwardから取得し、指定した場所に配置してください。個人用CSVと業務計画書は `.gitignore` で除外しています。

取引先は登録番号の完全一致を優先し、次に正規化した取引先名・検索キーを照合します。曖昧な名前は候補として表示し、利用者が選択します。確定した取引先コードはDBに保存し、CSVにはマスタの正式名を借方取引先として出力します。マスタCSVを追加・更新したときはアプリを再起動して読み込み直してください。
